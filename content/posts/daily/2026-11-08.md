一项预注册研究发现，运行时或 API 迁移后，用典型输入、要求全部断言通过的发布检查，会放行 0.410 的由大语言模型给出的错误修复；按版本说明写一条边界输入，就把这一比例降到 0.065 [1]。另一项工作提出 DictLLM，不再训练就把 LLaMA-7B 压缩 5.1 倍，WikiText-2 困惑度只增加 2.9 [2]。

## 统一系统观解读

统一系统观是什么，见[关于页](/about/)。本期两篇论文都可在 arXiv 阅读；第 1 条的 arXiv 条目注明 Preregistered，第 2 条注明 NeurIPS 2026 [1]、[2]。

**第 1 条：运行环境升级后，AI 修好的代码能跑通、结果却是错的，常规发布检查能不能拦住。**

背景：摘要称，运行时或 API 迁移后，由大语言模型修复的程序可能运行顺利却返回错误结果，而用典型测试输入做的发布检查会把它放行 [1]。

Xiaobo Chen、Genliang Zhu、Ziyuan Wang 与 Chu Wang 四位作者于 2026-11-05 在 arXiv 公开论文《Accepted but Wrong: Silent Failures of LLM Code Repairs after API Migrations》，报告一项预注册研究：73 项任务，覆盖 CPython、Node.js 与 SQLite 中有文档记录的 60 处变更；每个候选修复都在真实运行时上、对照不公开的契约执行 [1]。（本站补充的通用解释：预注册指在实验前公开登记研究假设与检验方法。）

为什么重要：在完整的修复空间上，用典型输入、要求全部断言通过的发布关口，放行了 0.410 的错误修复 [1]。按版本说明写的一条边界输入把这一比例降到 0.065，在 15 个未见过的簇上为 0.061；由从未看到程序的 GPT-5.6-luna 盲写的三条输入达到 0.070 [1]。但在加入 233 个在典型输入上与旧输出一致的高难干扰程序后，仍有 0.168 与 0.153 的高难错误程序通过 [1]。

卡在哪：相关产物只能向作者索取；盲审 AI 把 34 份契约标为比需求更严，去掉有争议的检查后没有判定改变，但类别标签上的争议仍未解决 [1]。

接下来看什么：这是本站自己的观察要点，不是论文的结论：其他团队在别的语言或运行时迁移上，是否也发现仅靠典型输入的发布检查会放行约四成的错误修复，而加一条按版本说明写的边界输入就能把比例压到一成以下。

**第 2 条：不重新训练，能不能把大语言模型压得更小，好放进手机。**

背景：摘要称，在移动设备上高效部署大语言模型，需要在性能与算力、内存约束之间取得平衡；训练后压缩是有效办法，所需计算远少于在训练中压缩 [2]。

Jinho Park、Se Young Chun 与 Mingoo Seok 三位作者于 2026-11-05 在 arXiv 公开论文《DictLLM: Post-training Compression of Large Language Model with Dictionary Kernels》（条目注明 NeurIPS 2026），提出 DictLLM：把分组层内的权重矩阵分解为一个共享字典和各层专属的稀疏系数，直接从预训练模型得到、无需再训练；每个层组只存一个共享字典加各层的稀疏系数，从而减少内存占用 [2]。

为什么重要：DictLLM 把原始 LLaMA-7B 压缩 5.1 倍，WikiText-2 困惑度只增加 2.9，压缩比是现有最佳低秩方法的 3.6 倍 [2]。（本站补充的通用解释：困惑度衡量语言模型预测文本时的不确定程度，越低越好。）

{{< industry-link item="2" industry="ai" side="cost" inference="更小的模型占用是否对应设备端部署的实际硬件成本下降" >}}来源报告的是模型压缩倍数及对应的困惑度增幅 [2]，对应这个产业里在设备端部署大语言模型一类的内存成本。{{< /industry-link >}}

卡在哪：摘要给出的是语言建模与零样本推理基准上的结果，困惑度仍有 2.9 的增幅，未报告在手机上实际运行的速度或内存数据 [2]。

接下来看什么：这是本站自己的观察要点，不是论文的结论：其他团队在更大的模型或真实移动设备上，用无需再训练的字典式压缩，能否保住约 5 倍的压缩比，同时把困惑度增幅控制在约 3 以内。

## API 迁移后：AI 修复的代码静默出错

**1. Accepted but Wrong: Silent Failures of LLM Code Repairs after API Migrations（通过了却是错的：API 迁移后大语言模型代码修复的静默失败）**

> Over the complete repair space, the all-assertions gate on typical inputs released 0.410 of wrong repairs.
>
> 译文：在完整的修复空间上，用典型输入、要求全部断言通过的发布关口放行了 0.410 的错误修复。

> One edge input written from the release note cut this to 0.065, and to 0.061 on 15 unseen clusters.
>
> 译文：按版本说明写的一条边界输入把这一比例降到 0.065，在 15 个未见过的簇上为 0.061。

## DictLLM：用共享字典压缩大语言模型

**2. DictLLM: Post-training Compression of Large Language Model with Dictionary Kernels（DictLLM：用字典核对大语言模型做训练后压缩）**

> DictLLM compresses the original LLaMA-7B model by 5.1x with only a 2.9-point increase in WikiText-2 perplexity, achieving a 3.6x higher compression ratio than the state-of-the-art low-rank method.
>
> 译文：DictLLM 把原始 LLaMA-7B 模型压缩 5.1 倍，WikiText-2 困惑度只增加 2.9，压缩比是现有最佳低秩方法的 3.6 倍。

一手来源：arXiv:2611.08082，2026-11-05 提交（UTC）；条目注明 NeurIPS 2026 [2]。
