{{- /* 页面描述：返回一个字符串，供 （meta-description.html）和首页、列表每行的摘要共用。 用法：partial "page-description.html" (dict "page" 页面 "fallback" 是否在取不到时退回首页描述)。meta 标签传 true；列表摘要传 false，取不到就返回空串、不显示摘要行。 中英文各取本语言的 i18n 和正文。取值优先级： 1. front matter 里的 description；2. i18n 的 meta_desc_<键>：首页 home，404 页 404，其余按路径（/posts/daily → posts_daily，标签页 tags、分类页 categories，依此类推）； 3. 普通文章（Kind 为 page）没有对应键时取渲染后正文的第一个
