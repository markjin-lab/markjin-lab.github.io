{{- /* 清洗一段描述文字（返回字符串）：去掉出处编号（[1]、链接文字为数字的链接，及以空白、顿号或逗号相连的一串编号）、 [文字](地址) 形式的 Markdown 行内链接只留文字、去 HTML 标签并还原实体、去首尾空白、合并空白。 参数可以是字符串（去掉所有出处编号；meta description 用），也可以是 dict "text" 文字 "end_cites_only" true： 这时只去掉句末的出处编号（编号串后面紧接 。！？.!? 或段末，中间可以隔着闭合引号、括号或「…」），连同编号前的空白（含 U+00A0 等 Unicode 空白），句中的编号原样保留（首页和列表摘要、list_summary 校验用，#109）。 page-description.html（meta 与列表摘要）和 list-summary.html（list_summary 校验时取导语）共用，保证摘要与 list_summary 校验对导语的处理逐字一致。 */ -}} {{- $s := . -}} {{- $endOnly := false -}} {{- if reflect.IsMap . -}}{{- $s = .text -}}{{- $endOnly = .end_cites_only | default false -}}{{- end -}} {{- $cites := `\s*\[\d+\](\s*[、,，]?\s*\[\d+\])*` -}} {{- $s = replaceRE `\[]*>(\d+)\]` "[$1]" $s -}} {{- $s = replaceRE `]*>\[?(\d+)\]?` "[$1]" $s -}} {{- if not $endOnly -}}{{- $s = replaceRE $cites "" $s -}}{{- end -}} {{- $s = replaceRE `\[([^\]]+)\]\([^)]+\)` "$1" $s -}} {{- $s = $s | plainify | htmlUnescape | strings.TrimSpace -}} {{- /* 句末编号：编号串（含编号之间的顿号、逗号和空白）后面可以先有闭合引号、括号或「…」，再接 。！？.!? 或段末；编号前的空白含 U+00A0 等 Unicode 空白（#112 r2） */ -}} {{- if $endOnly -}}{{- $s = replaceRE `[\s\p{Z}]*\[\d+\](?:[\s\p{Z}]*[、,，]?[\s\p{Z}]*\[\d+\])*((?:[”’」』）)\]】》"']|…)*[\s\p{Z}]*(?:[。！？.!?]|$))` "$1" $s -}}{{- end -}} {{- $s = replaceRE `\s+` " " $s -}} {{- return $s -}}
